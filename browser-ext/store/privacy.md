# Chrome Web Store — Privacy practices tab

**Privacy policy URL:** https://mafold.com/privacy

**Are you the developer or are you an agent of the developer?** Developer.

## What user data do you collect?

| Category | Collected? | Why |
|---|---|---|
| Authentication information (cookies) | **Yes** | Only for the sites the person picks, handed to the person's own Mafold desktop app on the same machine. |
| Web history | No | |
| Website content | No | The extension never reads page content or injects scripts. |
| Personal communications | No | |
| Location, financial, health, personal identifiers | No | |
| Activity / analytics | No | No telemetry of any kind. |

## Required certifications

- **I do not sell or transfer user data to third parties**, outside of the
  approved use cases. (There are none: the data goes only to the person's own
  Mafold app on the same computer, over a local channel.)
- **I do not use or transfer user data for purposes unrelated to the item's
  single purpose.**
- **I do not use or transfer user data to determine creditworthiness or for
  lending purposes.**

## Where the data goes

The picked sites' cookies travel from Chrome to the Mafold desktop app over a
local native-messaging channel on the same machine. They are **never** sent over
the network and **never** reach Mafold's servers. Mafold's handling of the data
once it is in the app is covered by the Mafold privacy policy above.
