# Chrome Web Store — listing copy

**Name:** Mafold Browser Import

**Summary (≤132 chars):**
Share the sign-ins for sites you pick with the Mafold app on your computer, so your agents can work in them. Nothing leaves your machine.

**Category:** Workflow & Planning

**Language:** English

## Description

Mafold Browser Import is a companion to the Mafold desktop app.

The Mafold app runs your agents in its own browser. For them to work in the sites
you already use, the app needs those sites' sign-ins. On macOS the app reads them
itself. On Windows, Chrome locks its login files so no other app can read them —
so the app asks Chrome, through this extension.

**You stay in control:**

- You pick which sites to share, in the Mafold app. The extension only ever sees
  the sites you picked.
- Chrome asks you to approve access to exactly those sites, and nothing wider.
- The sign-ins go straight to the Mafold app on the same computer, over a local
  channel. They never touch the internet and never reach Mafold's servers.
- The extension never reads the pages you browse, never changes any site, and
  never runs in the background on sites you didn't pick.

Remove the extension and nothing of it is left behind.

**You need the Mafold desktop app for this extension to do anything.** Get it at
https://mafold.com.

## Single purpose (required field)

This extension has one purpose: to hand the cookies of sites the person
explicitly picks to the Mafold desktop app on the same machine, over a local
native-messaging channel, so the person's own agents can use those sign-ins.
